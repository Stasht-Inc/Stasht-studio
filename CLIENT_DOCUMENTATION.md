# Stasht Studio — User Guide

Welcome to **Stasht Studio**! This guide explains what the platform does and how to use every part of it. It's written for everyday use — no technical background needed.

## What is Stasht Studio?

Stasht Studio is a platform for creating and sharing **"Stories"** (also called **Campaigns**) — collections of photos, videos, and memories, organized into a timeline you can share with friends, family, customers, or the public. You can invite people to contribute, moderate what gets shown, track how many people view and engage with your stories, and even sell products or collect signatures directly inside a story.

## 1. Getting Started — Creating Your Account

When you first visit Stasht Studio, you'll see a **Sign Up** screen. You do not need to create or remember a password — instead, the app confirms who you are with a one-time code.

**Steps to sign up:**

1. Enter your full name.
2. Choose whether to sign up with a **phone number** or an **email address**, and enter it.
3. Tick the box agreeing to the Terms of Service and Privacy Policy.
4. Click the sign-up button. A 6-digit code will be sent to your phone or email.
5. Enter that code on the next screen and click **Verify OTP**. (OTP stands for "one-time password" — just a temporary code.)
6. If the code doesn't arrive, wait 60 seconds and click **Resend OTP**. The code expires after 10 minutes.

Once verified, your account is created and you're taken straight into the app.

**Faster options:** You can also click **Continue with Google** or **Continue with Apple** to sign up instantly using an existing Google or Apple account — no code needed. If you sign up with Google, you'll be asked whether you'd like to connect Google Photos as well (you can choose "Connect" or "Maybe Later").

## 2. Signing In

Returning users sign in from the **Login** screen, using the same code-based approach:

1. Choose **phone number** or **email address** and type it in.
2. Click **Send OTP** to receive your 6-digit code.
3. Enter the code and click **Verify OTP**.

You can also sign in instantly with **Continue with Google** or **Continue with Apple**.

If you forget how you signed up, there's a **Forgot password?** link to help recover your account. If your account hasn't been activated yet, a message will appear with a button to resend your activation code.

**Account activation link:** If you signed up by email, you may also receive an activation link. Clicking it opens a page that automatically confirms your account within a few seconds — you don't need to do anything but wait. If the link has expired, you'll see a **Try Again** button or a **Back to Login** button.

## 3. Joining Someone Else's Account or Property

Sometimes you'll be invited to join someone else's account (as a collaborator) or a specific **Property** (a location or workspace, such as a store or venue). You'll receive a special invite link by email or text.

Clicking the link opens a registration page that already shows who invited you. Fill in:

- Your first and last name
- A phone number or email
- A password (for brand-new users only — you'll see a checklist showing the password needs at least 8 characters, one uppercase letter, and one number)

If the phone/email you enter already matches an existing Stasht account, the app recognizes you automatically and simply asks you to click **Join Account** (or **Join Property**) — no need to re-enter your name or set a password.

After joining, you'll see a success message and be automatically taken to the Login screen with your details already filled in.

**Switching between accounts:** If you have access to more than one account or property (for example, your own personal account plus a few properties you help manage), a pop-up window will appear right after you log in, letting you choose which one to enter. You can always switch later from your profile menu.

## 4. Your Dashboard (the Memories Page)

This is your home screen — a library of every Story (Campaign) you've created, shown as a grid or list of cards. Each card shows a cover photo, title, category, author, and how many photos it contains.

**What you can do here:**

- **Search, filter, and sort** your stories (by category, author, or label).
- **Create a Campaign** — click this button to start a brand-new story. Give it a name and category, and optionally pull in photos you've already uploaded.
- **AI Wizard** — an assistant that suggests ways to organize or improve a story. It runs in the background so you can keep working while it thinks.
- Each story card has a menu with options to **Edit**, **Delete**, **Add Tags**, **Merge** (combine two stories into one), and **Publish** (turn it into a shareable web page — see [Section 8](#8-publishing-and-sharing-a-story)).
- If someone has invited you to collaborate on a story, you'll see an invite banner where you can **Accept** or **Reject**.
- Clicking any story card opens it up for editing (see the next section).

---

## 5. Building a Story (the Memory Details Page)

This is where you actually build a Story — adding photos, videos, captions, and more. Once you open a story, you'll see it organized into tabs:

### Overview
The main timeline of your story — a scrollable feed of "Moments" (individual posts with a photo or video, a caption, comments, and likes).

### Moderation
*(Only shown if you've turned this on.)* Lets you review and approve or reject photos and comments submitted by collaborators before they appear publicly. A badge shows how many items are waiting for your review.

### Analytics
Shows how many people have viewed your story, how they've engaged with it, and how many clicks any buttons (like "Buy Now") have received.

### Collaborators
Manage who can access this specific story and what they're allowed to do — View only, Edit, or full Admin access.

### Adding Content

- **Add a Moment** — upload a photo or video, write a caption, tag people, and add a location or date.
- **Voice-to-Text** — tap the microphone button and simply talk. Your words are automatically converted into text and split into separate Moments. You can even say "add a photo" while recording to mark a spot where a picture should go. Afterwards, you can review and edit the text before saving it. If your microphone doesn't work, step-by-step instructions appear to help you enable it.
- **AI Face Scan** — automatically detects and groups the people who appear across your photos (see [Section 7](#7-the-people-library)).
- **Widgets** — extra elements you can drop into your timeline, including:
  - An embeddable video (e.g. YouTube)
  - A pull-quote
  - A **Call-to-Action button** (e.g. "Buy Now," "Learn More," or a special "Share a Moment" button that lets visitors submit their own photo)
  - A product card if you've connected a Shopify store
- **DocuSign** — attach documents to your story that visitors can review and sign, with tracking on their status.

### Editing a Moment
Each photo/video post in the timeline can be edited: change the caption (there's an AI "suggest wording" helper with different tone options), replace the photo, delete the post, hide the caption, or reorder it within the timeline.

### Publishing Controls
From within a story you can make it **Public**, **View-Only**, or **Private**, generate a shareable link and QR code, and view a history of when it's been published.

## 6. The Media Library

This is your central photo and video library, pulling together everything uploaded across all your stories.

- **Browse** everything in a grid or list, and **search, sort, or filter** by date, name, size, or location.
- **Upload** new photos or videos by dragging them in or choosing files from your device.
- **Select multiple items** at once to move them into a story, download them, share them, delete them, or group them into a new Moment.
- **Connect external services** — link Google Photos, Dropbox, or Facebook so your media syncs in automatically. A progress bar shows syncing status, and you can disconnect a service at any time.
- Clicking any photo opens a full-size viewer showing details like location, date, and camera information.

---

## 7. The People Library

This section is automatically generated using AI face recognition. It groups your photos by the people who appear in them.

- Each card represents one person that's been detected, with a name (which you can edit), a cover photo, and a count of how many photos and stories they appear in.
- Click a person to open their profile, where you can:
  - Rename them and add tags
  - Change or crop their photo
  - Run another **AI Scan** to search for more photos containing that person (this uses "AI credits" — if you run low, a pop-up lets you purchase more)
  - Add more photos to their profile, from your device or from the Media Library
  - Delete individual photos, or remove the person entirely

## 8. Publishing and Sharing a Story

Once a story is ready to share, you can publish it as a public webpage. Anyone with the link (they don't need a Stasht account) can view it, and depending on your settings, they can:

- **Like and comment** on Moments
- **Share** the page via a copied link, email, or social buttons (Facebook, LinkedIn, Instagram), or scan a **QR code**
- Click a **"Share a Moment"** button (if you've enabled it) to submit their own photo and caption to your story

There's also an **Author page** — a landing page listing every story a particular author has published, so visitors can browse all of that person's shared stories in one place.

## 9. Managing Your Team (the Users Page)

This page is your hub for managing who has access to your account, split into four tabs:

- **All Users** — everyone with access, showing their role (Admin, Editor, Viewer, etc.) and status (active or pending invite). You can **Invite** new people by email, **edit their role**, or **deactivate/remove** their access.
- **Leads** — messages and inquiries from visitors to your published stories, organized as conversation threads.
- **Shared with** — stories that other Stasht users have shared with your account.
- **Properties** *(available on paid plans)* — separate branded sub-accounts (for example, individual store locations or venues), each with its own invite link and QR code. You can create a new property, view/switch into it, or transfer ownership of a story to a different property.

You can also **Export** your user list as a spreadsheet file at any time.

## 10. Connecting Other Services (Marketplace)

The Marketplace lets you connect Stasht Studio to outside services so their content flows automatically into your stories:

- **Shopify** — automatically sync your product photos in. Click **Get Widget**, enter your store's web address, click **Connect with Shopify**, and log in to approve the connection.
- **DocuSign** — attach signable documents to your stories. Click **Get Widget**, then **Connect with DocuSign** and log in through DocuSign.
- **AutoTrader** — sync vehicle listings in. This requires a Dealer ID, API Key, and API Secret, which you can get from AutoTrader support.

Once connected, a **Connected** badge appears on that service's card, and the button changes to **Manage**, where you can view details or **Disconnect** at any time.

## 11. Billing and Subscription Plans

The Billing page is where you manage your subscription and payments.

**What you'll see:**
- Your current plan name and price
- How much storage and how many "AI credits" you've used
- Any scheduled upcoming plan changes
- Saved credit/debit cards
- A history of past invoices (downloadable as PDFs)
- A log of your AI feature usage

**What you can do:**
- **Buy more Credits** — purchase additional AI credits in packages
- **Upgrade Plan** — compare and switch between plans:
  - **Starter** (free)
  - **Teams**
  - **Business**

  Each higher tier includes more storage, more AI credits, more team seats, and extra features like Property Accounts. You can choose Monthly or Yearly billing (yearly saves about 17%). After picking a plan, you'll choose a payment method and, for cards, enter your payment details on a secure form.

  If you downgrade to the free Starter plan, your current paid plan stays active until the end of the billing period, and no refund is given for the unused time.

- **Add or remove payment cards**
- **Cancel** a scheduled plan change before it takes effect
- **Download** any past invoice

## 12. Your Profile and Account Settings

This page holds all your personal account settings, organized into sections:

- **Personal Information** — your name, email, phone, location (with a button to auto-detect it), a short bio, your profile photo, and links to your social media profiles. You can also turn on a signature "e-business card" that appears on your stories.
- **Account Security** — change your password (with a strength meter showing how secure it is) and turn on two-factor authentication for extra protection.
- **Storage Management, Categories, Privacy, Notifications, App Preferences** — additional settings screens for fine-tuning how the app works for you.
- **Remove Account** — permanently delete your account, if needed.

Each section shows your current details with an **Edit** button. Click it to make changes, then **Save Changes** to confirm or **Cancel** to discard.

## 13. Developer Access (Apps Page)

This page is only relevant if you have a developer building a custom integration with Stasht Studio. It lets you generate secure credentials ("API Keys") that a developer can use to connect other software to your account.

- **Create API Key** — generate a new key and give it a name.
- Each key is masked for security; click the eye icon to reveal it temporarily, or **Copy** to copy it.
- **Delete** a key at any time (for example, if it's no longer needed or may have been compromised).
- **View Documentation** opens the technical reference your developer would use.

If you don't have a developer working with you, you can safely ignore this page.

## 14. Bulk Importing Properties (CSV Upload)

This is a tool for quickly creating many Properties at once, rather than one at a time. It's mainly intended for administrative use.

1. Prepare a spreadsheet (CSV or Excel file) listing the properties you want to create, along with one image web address to use for all of them.
2. Drag the file in and click **Import Properties**.
3. A summary appears showing how many rows were processed successfully, how many failed, and details on any errors — so you can fix and re-import if needed.

## 15. Running the Project (For Your Developer / Hosting Team)

> This section is technical and is meant for whoever will be hosting or maintaining the website on your behalf (a developer or IT person) — you don't need to do this yourself day-to-day.

The project is a website built using **Node.js**. To run it, your developer will need:

- **Node.js** installed on their computer (version 18 or newer is recommended).
- The project folder (all the files that make up the website).
- A filled-in **`.env` file** — a small configuration file containing keys/credentials for the outside services the app connects to (Google Sign-In, Google Places, Facebook Login, Apple Sign-In, Stripe payments, DocuSign, and Deepgram voice-to-text). A template already exists in the project; each key needs a real value obtained from that service's own dashboard (e.g. the Stripe key comes from the Stripe dashboard, the Google keys from Google Cloud Console, etc). **These keys are sensitive and should never be shared publicly or committed to a public code repository.**

**To view/test the site on a local computer (development mode):**

1. Open a terminal in the project folder.
2. Run `npm install` — this downloads everything the project needs (only required once, or after updates).
3. Run `npm run dev` — this starts the site locally.
4. Open a browser to `http://localhost:5173` to view it.

**To prepare the site for real visitors (production build):**

1. Run `npm run build:prod` — this packages the whole site into a folder named `dist`, optimized for speed.
2. Run `npm run server` — this starts a server that serves the packaged site (or run `npm start`, which does both steps in one command).

**Deploying to a hosting provider:**

The project already includes a ready-made configuration for **Netlify** (a popular hosting service) in a file called `netlify.toml`. It tells Netlify to run `npm run build:prod` and publish the resulting `dist` folder automatically. If Netlify is connected to the project's code repository, every update can be set up to publish automatically. Other hosting providers can also be used, as long as they run the same build command and serve the `dist` folder.
